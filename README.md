# RESTAURANTE XISTO FLAVOR 🤖🍽️

## 1. INTRODUÇÃO 👋

Este trabalho apresenta o desenvolvimento e a implementação de um **Chatbot** para o restaurante **Xisto Flavor**, utilizando a plataforma **Blip Portal**. O objetivo principal é **aprimorar a experiência do cliente**, permitindo que os usuários realizem tarefas importantes diretamente na conversa:

* **📝 Cadastro de Clientes:** Novos clientes podem se registrar de forma rápida e intuitiva.
* **🍔 Consulta ao Cardápio:** Explore os deliciosos pratos disponíveis no cardápio do restaurante.
* **💳 Realização de Pagamentos:** Efetue pagamentos com comodidade diretamente pelo chat.

Para uma interação mais inteligente e personalizada, o chatbot conta com:

* **📍 Integração com ViaCEP:** Informando o CEP, o sistema utiliza a API ViaCEP para identificar automaticamente a **UF** (Unidade Federativa) e o **Logradouro** do cliente. **Durante o desenvolvimento e testes desta integração, a ferramenta Postman foi utilizada para realizar requisições e analisar as respostas da API ViaCEP.**
* **✅ Validações de Dados:** Implementamos verificações rigorosas nos seguintes blocos para garantir a qualidade das informações:
    * 👤 Obter Nome
    * 📞 Obter Telefone
    * ✉️ Obter CEP
    * 🎂 Obter Data de Nascimento
    * 🔑 Obter CPF
    * 📧 Obter Email
    * 🗺️ Obter Logradouro

## 🛠️ TECNOLOGIAS UTILIZADAS

* **💬 Blip Portal:** Plataforma de desenvolvimento de chatbots utilizada neste projeto.
* **🗺️ ViaCEP API:** Serviço web para consulta de informações de endereços a partir do Código de Endereçamento Postal (CEP).
* **⚙️ Postman:** Ferramenta utilizada para testar e interagir com a API ViaCEP durante o desenvolvimento.

## 📝 OBSERVAÇÕES

Este projeto demonstra a criação de um chatbot funcional com foco na melhoria da experiência do cliente do restaurante Xisto Flavor. As validações implementadas asseguram a integridade dos dados, e a integração com o ViaCEP, testada com o auxílio do Postman, proporciona um atendimento mais ágil e personalizado.
